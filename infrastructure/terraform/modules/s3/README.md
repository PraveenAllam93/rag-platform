
### S3 Buckets

Every bucket in S3 should include:

- Versioning (recovery from accidental deletion)
- SSE Encryption (encrypt data at rest)
- Public Access Block (prevent accidental exposure)
- Ownership Controls (consistent object ownership)
- HTTPS-only Policy (block insecure transport)
- Tags (Cost tracking)
- Lifecycle Rules (Reduce storage cost - optional)
- Access Logging (Audit)
- Replication (disaster recovery)
